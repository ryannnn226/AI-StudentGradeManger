# AI 智能学生成绩管理系统 - 安装说明

## 系统要求

- **操作系统**：Windows 10 / Windows 11（64位）
- **运行时**：.NET 9.0 Desktop Runtime
- **磁盘空间**：至少 100 MB 可用空间

## 安装步骤

### 1. 安装 .NET 9.0 运行时

如果尚未安装，请从微软官网下载：
https://dotnet.microsoft.com/download/dotnet/9.0

选择 **.NET Desktop Runtime 9.0** 下载安装。

验证安装：打开命令提示符，输入 `dotnet --version`，应显示 `9.0.x`。

### 2. 获取程序文件

将整个 `StudentGradeManager` 文件夹复制到目标计算机。

### 3. 配置 DeepSeek API Key

编辑 `appsettings.json` 文件，将 `ApiKey` 的值替换为你的 DeepSeek API Key。

```json
{
  "DeepSeek": {
    "ApiKey": "你的API密钥",
    "BaseUrl": "https://api.deepseek.com/v1",
    "Model": "deepseek-chat"
  }
}
```

> 注：若不配置 API Key，AI 分析功能不可用，其他功能正常。

### 4. 运行程序

双击 `StudentGradeManager.exe` 启动。

首次运行自动创建数据库并初始化示例数据。
