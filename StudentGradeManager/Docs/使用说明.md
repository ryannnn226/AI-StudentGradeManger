# AI 智能学生成绩管理系统 - 使用说明

## 快速入门

### 登录系统
1. 启动程序进入登录界面
2. 输入用户名和密码
3. 点击"登录"（或按回车键）
4. 系统根据角色自动跳转对应界面

## 角色功能

### 管理员（admin）
拥有系统全部权限：
- **学生管理**：添加、编辑、删除学生信息
- **课程管理**：添加、编辑、删除课程信息
- **成绩管理**：录入、删除成绩记录
- **成绩统计**：查看各课程平均分、最高/低分、及格率、班级排名
- **AI 智能分析**：选择学生，使用 AI 分析成绩趋势或生成评语
- **用户管理**：添加、删除系统用户

### 教师（teacher1 / teacher2）
- **成绩录入**：为学生录入各科成绩（期中/期末/平时）
- **成绩统计**：查看各课程成绩统计
- **AI 智能分析**：查看学生成绩趋势分析

### 学生（student1、student2、student3）
- **我的成绩**：查看个人所有成绩和统计摘要
- **AI 智能分析**：获取 AI 成绩分析和学期评语

## 常用操作

### 添加学生
1. 切换到"学生管理"标签页
2. 点击"添加学生"
3. 填写学号、姓名、性别、班级等
4. 点击"确定"

### 录入成绩
1. 切换到"成绩管理"标签页（管理员）或主界面（教师）
2. 选择学生、课程，输入分数（0-100），选择考试类型和日期
3. 点击确定

### 查看统计
1. 切换到"成绩统计"标签页
2. 点击"刷新统计"
3. 点击"查看班级排名"查看各班平均分排名

### AI 分析
1. 切换到"AI 智能分析"标签页
2. 选择学生
3. 点击"成绩波动分析"或"生成评语"
