# AI 智能学生成绩管理系统 - 帮助文档

## 常见问题

### Q: 忘记密码怎么办？
A: 联系管理员重置。管理员可删除旧账号重新创建（默认密码 123456）。

### Q: 程序无法启动？
A: 确认已安装 .NET 9.0 Desktop Runtime；确认 `appsettings.json` 文件存在于程序目录。

### Q: AI 分析无法使用？
A: 确认 `appsettings.json` 配置了有效的 DeepSeek API Key；确认网络可访问；确认 Key 有可用额度。

### Q: 数据库文件在哪？
A: 程序目录下 `StudentGrade.db`。删除后重新运行将重建数据库。

## 数据备份
定期备份 `StudentGrade.db` 文件，直接复制即可。

## 技术架构
- **前端**：Windows Forms (.NET 9.0)
- **语言**：C#
- **数据库**：SQLite（Microsoft.Data.Sqlite）
- **AI 接口**：DeepSeek API（OpenAI 兼容格式）

## 数据库表

| 表名 | 说明 | 主要字段 |
|------|------|----------|
| Users | 用户表 | Username, PasswordHash, Role, FullName |
| Students | 学生表 | StudentNo, Name, Gender, Class, Phone, Email |
| Courses | 课程表 | CourseNo, Name, Credit, Teacher, Semester |
| Grades | 成绩表 | StudentId, CourseId, Score, ExamType, ExamDate |

## 注意事项
1. 分数范围 0-100
2. 删除学生/课程时同时删除关联成绩
3. 管理员账号 admin 不可删除
4. AI 分析需要网络连接
